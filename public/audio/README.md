# Keyboard Sound Assets

Place the following audio files in this directory:

- `tick_1.wav` - Short keyboard tick sound (30-120ms)
- `tick_2.wav` - Alternative keyboard tick sound (30-120ms)
- `space.wav` (optional) - Space key sound
- `enter.wav` (optional) - Enter key sound

The sounds should be:
- Short one-shot samples (30-120ms duration)
- Professional keyboard tick sounds
- WAV format for best browser compatibility

The system will randomly select between tick_1 and tick_2, apply random volume/pitch variations, and play sparsely (30% probability with cooldown).
